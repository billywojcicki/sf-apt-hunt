# SF Apartment Hunt

Apartment listings in San Francisco with a Dec 15, 2026 to Jan 15, 2027 move-in: 1BR+, 600+ sq ft, laundry in unit or building, under $6,000/mo.

Live site: https://billywojcicki.github.io/sf-apt-hunt/

- `index.html` is the page.
- `data/listings.json` holds the listings. `data/meta.json` holds the last refresh date.

Facts come from each listing page on the date shown. Confirm with the landlord before applying or paying anything.

- Contact / Contacted / Pass marks and notes save in your own browser only.
