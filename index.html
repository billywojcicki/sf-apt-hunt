SF Apartment Hunt

Move-in target Jan 1, 2027. 1BR+ (2BR bonus), 600+ ft², laundry in unit or building, $6,000 max. Pulled Oct 1-10 from Craigslist, Zumper, Compass, Redfin, RentCafe, Apartments.com and ~25 SF property managers.

The Jan 1 problem

Few listings name a Jan 1 date yet. SF landlords list 30-45 days ahead, so real Jan 1 stock appears mid-Nov to early Dec. Use this list to ask which landlords will hold or start a lease later.

Utilities

None of these include utilities. "All-in" assumes about $200/mo for PG&E and internet.
